# Database Finder

ابزار ویندوزی برای پیدا کردن دیتابیس‌های در حال اجرا روی سیستم.

> **English:** [Read English README](README.md)

قابلیت تشخیص انواع دیتابیس زیر را دارد:
- SQL Server
- MySQL
- MariaDB
- PostgreSQL
- Oracle
- MongoDB
- Redis
- Elasticsearch
- CouchDB

## تغییرات نسخه ۱.۸.۸

- **رفع باگ «انتخاب پوشه دستی»:** حتی وقتی روی گروه کلیک شده یا هیچ انتخابی نیست کار می‌کند (اولین مورد خطادار را خودش پیدا می‌کند)، برای جایگزینی فایل‌های خودکار تاییدیه می‌گیرد و تیک دیتابیس را خودکار می‌زند.

## تغییرات نسخه ۱.۸.۷

- **بکاپ بدون پسورد sa:** وقتی ورود به SQL ناموفق است، «کپی فایل‌ها» متوقف نمی‌شود؛ مسیر MDF/LDF از رجیستری/سرویس پیدا و با VSS کپی می‌شود (بدون پسورد). فایل‌ها را بعدا در آزمایشگاه Attach کنید.
- **یافتن پسورد ذخیره‌شده (دستی):** دکمه «یافتن پسورد ذخیره‌شده» فقط با کلیک شما و فقط پوشه‌های مشکوک (محک/هلو/پارسیان...) را می‌گردد — عمدا اتوماتیک نیست.
- **sysadmin اضطراری (دستی):** دکمه قرمز «sysadmin اضطراری» فقط با Administrator و تایید دو مرحله‌ای؛ اعطای sysadmin در حالت تک‌کاربره با ثبت کامل در لاگ و مانیفست ماده ۱۸۱.

## تغییرات نسخه ۱.۸.۶

- **به‌روزرسانی داخلی:** هنگام اجرا، برنامه آخرین نسخه را از ریلیزهای GitHub (مخزن iranacc/DatabaseFinder) می‌خواند و با نسخهٔ خودش مقایسه می‌کند؛ اگر نسخهٔ جدیدتری موجود باشد، بالای صفحه لینک «نسخهٔ جدید … آماده است — به‌روزرسانی» و در منوی سینی ویندوز «بررسی به‌روزرسانی» نشان داده می‌شود. با کلیک، فایل با نمایش درصد دانلود، صحت‌سنجی SHA-256 با `SHA256SUMS.txt` ریلیز، جایگزینی خودکار و راه‌اندازی مجدد انجام می‌شود. نسخهٔ مناسب خودکار انتخاب می‌شود (Light بر اساس لایت، مستقل بر اساس مستقل).
- **عنوان پنجرهٔ واقعی:** عدد عنوان برنامه دیگر ثابت نیست و نسخهٔ واقعی فایل اجراییِ در حال اجرا را نشان می‌دهد.

## تغییرات نسخه ۱.۸.۵

- **رفع باگ مقصد بکاپ:** فهرست بکاپ فقط یک بار هنگام باز شدن پنجره ساخته می‌شد؛ با تغییر مقصد، فایل‌ها به پوشهٔ پیش‌فرض می‌رفتند ولی گزارش/مانیفست در مقصد جدید (خالی) ساخته می‌شد. حالا با هر تغییر مقصد فهرست دوباره ساخته می‌شود (تیک‌ها حفظ می‌شوند) و بکاپ واقعاً به پوشهٔ انتخابی می‌رود.
- **گزینه‌های بکاپ SQL Server:** فشرده‌سازی (COMPRESSION)، تأیید صحت پس از اتمام (VERIFYONLY) و Checksum هنگام نوشتن روی رسانه (CHECKSUM).
- **مانیفست کامل و زیبا:** سه فایل `manifest.txt` (قاب‌بندی‌شده با مهر ۱۸۱، خلاصهٔ اجرا، کارت هر دیتابیس، جدول هش و بلوک سازگار با `sha256sum -c`)، `manifest.md` و `manifest.json` تولید می‌شود؛ نسخهٔ سرویس‌ها زنده پرس‌وجو و هش مانیفست داخل خودش درج می‌شود.
- **مهر مادهٔ ۱۸۱:** لوگوی بزرگ ۱۸۱ (مادهٔ ۱۸۱ قانون مالیات‌های مستقیم) با متن «TAX 181 ARTICLE . MSAM Group» بالای مانیفست چاپ می‌شود.
- **فهرست دیتابیس‌ها:** دابل‌کلیک روی ستون «تعداد دیتابیس‌ها» فهرست نام دیتابیس‌های همان سرویس را باز می‌کند.

## تغییرات نسخه ۱.۸.۴

- اسکن رنج شبکه: اسکن یک بازه از IP، یک شبکهٔ محلی (رنج کارت‌های شبکه به‌صورت خودکار در منوی کشویی می‌آید) یا یک آدرس CIDR با هم‌زمانی محدود و مهلت هر میزبان؛ برای هر یافت‌شده نام نمونه و نسخه با پرس‌وجوی SQL Browser (SSRP / UDP 1434) هم به‌دست می‌آید.
- فیلتر «فقط پورت‌های باز» در اسکن شبکه (پیش‌فرض فقط باز؛ با یک تیک همهٔ میزبان‌ها دیده می‌شوند).
- شناخت SQL Server بدون SSMS به‌کمک پرس‌وجوی SSRP.
- احراز هویت ویندوز در «اجرای کوئری» (Integrated Security) با یافتن خودکار نام میزبان برای آدرس IP.
- ستون «تعداد دیتابیس‌ها» در صفحهٔ اصلی: تعداد واقعی دیتابیس‌های هر سرویس آنلاین (با پروفایل ذخیره‌شده یا احراز هویت ویندوز).
- دکمهٔ Close واقعاً برنامه را می‌بندد (کوچک‌کردن همچنان به سینی می‌رود) و «اجرای کوئری» روی هر ردیف انتخابی اسکن شبکه کار می‌کند.

## تغییرات نسخه ۱.۸.۳

- اصلاح بسته‌بندی نسخهٔ تک‌فایلی: همهٔ فایل‌های بومی (از جمله کتابخانهٔ اتصال به SQL Server) داخل خود فایل اجرایی قرار می‌گیرند؛ دیگر نیازی به فایل جدا کنار exe نیست و «کشف فایل» SQL Server بدون خطا کار می‌کند. گزینهٔ بسته‌بندی در فایل پروژه نیز ثبت شده است.

## تغییرات نسخه ۱.۸.۲

- رفع باگ نسخه ۱.۸.۱: شناسایی دیتابیس‌ها دیگر بعد از اولین اسکن قفل نمی‌شود؛ دیتابیس‌هایی که خودشان بنر نمی‌فرستند (مثل SQL Server) دیگر تست را برای همیشه معلق نمی‌کنند. تست اتصال حالا مهلت سراسری ۵ ثانیه‌ای دارد و هر بار روی Refresh دوباره تشخیص واقعی اجرا می‌شود.
- تشخیص بکاپ‌های نرم‌افزارهای حسابداری ایرانی در اسکن آفلاین: محک (الگوهای `Backup-mahak…`، `Auto-mahak…`، `BeforeUpdate…`، `FullBackup-…`، `ver…`)، پارسیان (پوشهٔ `PARSIAN.BACK`) و هلو (پوشهٔ `Holoo.Bak`). این پوشه‌ها به مسیرهای جست‌وجوی سریع هم اضافه شدند.
- اولویت‌بندی تطبیق در اسکن فایل: مسیر پوشه → الگوی نام فایل → پسوند.

## تغییرات نسخه ۱.۸.۱

- بهبود کارایی شناسایی پورت‌ها: مپ پورت→PID حالا با یک بار اجرای netstat ساخته می‌شود (پیش از این برای هر پورت یک بار اجرا می‌شد).
- تست اتصال برای دریافت نسخه به حالت غیرمسدودکننده با مهلت ۵ ثانیه‌ای تبدیل شد؛ رابط در شبکه‌های کند یخ نمی‌زند و ردیف‌ها با پایان تست به‌روز می‌شوند.
- نسخه به‌دست‌آمده با شاخص به ردیف جدول می‌رود، نه با تطبیق نام+پورت.
- کاهش تشخیص اشتباه MySQL (فقط فرآیند mysqld/mysql شناسایی می‌شود).
- لاگ فنی خطاهای بلعیده‌شده در تنظیمات، پروفایل‌ها، شناسایی، مانیفست و Shadow Copy (`%AppData%\DatabaseFinder\debug.log`).
- افزودن فایل راه‌حل (solution) برای ساخت یکپارچه همه پروژه‌ها.

## تغییرات نسخه ۱.۸

- بازطراحی رابط با منوی کناری، رنگ‌بندی یکپارچه، نوار انتخاب و پنل مسیر و جزئیات.
- تغییر زبان فارسی / English از بالای صفحه اصلی؛ زبان ذخیره می‌شود و نتایج و تیک‌ها هنگام تغییر زبان حفظ می‌شوند.
- پنجره جست‌وجو و انتخاب فرمت شامل هر ۱۱ گروه و ۲۸ پسوند؛ انتخاب مستقل پسوندها و حفظ انتخاب‌ها هنگام فیلتر کردن فهرست.
- چیدمان منعطف برای اسکن فایل، کپی، بکاپ، تنظیمات، اجرای کوئری، اسکن شبکه، پروفایل و جزئیات.
- متن‌های برنامه و پیام‌های عملیاتی در منابع ترجمه مجزا نگهداری می‌شوند؛ مسیرها، نام دیتابیس‌ها، کوئری‌ها و کلیدهای مانیفست ساختاریافته تغییر نمی‌کنند.

## قابلیت‌ها (نسخه ۱.۸)
- شناسایی از ۳ روش: سرویس ویندوز، پروسس، پورت‌های باز
- **انتخاب حالت جستجو** — تعیین کنید فقط آنلاین (در حال اجرا)، فقط آفلاین (اسکن هارد) یا هر دو
- **اسکن آفلاین هارد دیسک** — پیدا کردن فایل‌های دیتابیسی که در حال اجرا نیستند (سرویس متوقف‌شده، دیتابیس پاک‌شده از سرویس و بکاپ‌ها):
  - انتخاب فارمت‌های مورد جستجو: SQL Server (mdf/ldf/ndf)، بکاپ‌های SQL Server (bak)، MySQL InnoDB/MyISAM، SQLite، Access، FoxPro/dBase (رایج در نرم‌افزارهای حسابداری ایرانی)، Firebird، MongoDB WiredTiger، Redis، آرشیوهای بکاپ عمومی
  - اسکن سریع (پوشه‌های رایج) یا اسکن کامل (کل درایوهای ثابت)، فیلتر حداقل اندازه، انتخاب جداگانه مکان‌ها، افزودن پوشه دلخواه، توقف با نمایش پیشرفت
  - دکمه «انتخاب همه» و «هیچ» برای لیست مکان‌ها و لیست فرمت‌ها
  - **بررسی اصالت محتوا (امضای فایل)** — فایل‌ها علاوه بر پسوند، با امضای محتوایشان هم سنجیده می‌شوند؛ بنابراین فایل‌هایی مثل `Acrobat.dll.bak` یا `Photoshop.exe.bak` دیگر به‌عنوان بکاپ SQL شناخته نمی‌شوند
  - لیست نتایج با فارمت، **فرمت فایل (پسوند)**، نام حدسی دیتابیس، اندازه، تاریخ تغییر و علامت بکاپ
  - **انتخاب/لغو انتخاب در نتایج** — کلیک روی هر جای ردیف تیک را روشن/خاموش می‌کند و دکمه‌های «انتخاب همه» و «هیچ» بالای جدول نتایج
  - **منوی راست‌کلیک روی نتایج** — باز کردن پوشه فایل، باز کردن فایل، کپی مسیر کامل و کپی فایل به پوشه دلخواه
- حداقل اندازه فایل در تنظیمات اسکن بر حسب **مگابایت** (پیش‌فرض 3MB)
- با انتخاب «فقط آفلاین» برنامه به‌صورت خودکار صفحه اسکن هارد را باز می‌کند
- آیکن چنداندازه برنامه در تسک‌بار و نوار عنوان
  - کپی مستقیم نتایج آفلاین یا افزودن آن‌ها به جدول اصلی برای استفاده از قابلیت کپی
- جزئیات کامل هر دیتابیس (نسخه، آدرس، وضعیت سرویس/پروسس)
- اتصال واقعی و اجرای کوئری (MySQL، PostgreSQL، SQL Server، SQLite، Redis)
- اسکن سیستم‌های راه دور (شناسایی دیتابیس‌های در حال اجرا روی سایر سیستم‌های شبکه)
- کپی فایل‌های فیزیکی دیتابیس (آنلاین و آفلاین) در پوشه جداگانه هر دیتابیس با نام اصلی فایل‌ها
  - SQL Server: لیست فایل‌ها از sys.databases و master_files (بدون دیتابیس‌های سیستمی)
  - MySQL/MariaDB: پوشه جداگانه هر دیتابیس از دایرکتوری داده سرور
  - PostgreSQL: دایرکتوری‌های هر دیتابیس از base/ (بر اساس OID)
  - Redis: فایل‌های dump.rdb / appendonly از CONFIG GET dir
  - MongoDB: شناسایی خودکار دایرکتوری داده (\data\db)
  - انتخاب دستی پوشه به‌عنوان جایگزین
  - **حالت برخورد با فایل‌های قفل‌شده (در حال اجرا)** — در پنجره کپی قابل انتخاب است:
    - **Shadow Copy (VSS) بدون توقف سرویس (پیشنهادی):** فایل‌های قفل‌شده از snapshot حجم در حالی که سرویس دیتابیس در حال اجراست کپی می‌شوند (نیاز به اجرا به‌عنوان Administrator)
    - **توقف و شروع مجدد خودکار سرویس دیتابیس:** سرویس‌های مربوط (sqlservr/mysqld/postgres) به‌صورت خودکار برای کپی متوقف و پس از آن حتماً دوباره راه‌اندازی می‌شوند
    - **فقط گزارش خطا:** فایل‌های قفل‌شده به‌عنوان خطا گزارش می‌شوند (رفتار نسخه‌های قبلی)
- **بکاپ منطقی دیتابیس‌های در حال اجرا** — ساخت نسخه پشتیبان با ابزارهای بومی دیتابیس در یک پوشه جداگانه برای هر دیتابیس:
  - SQL Server: دستور `BACKUP DATABASE ... TO DISK` (با فشرده‌سازی)
  - MySQL/MariaDB: `mysqldump` با یافتن خودکار فایل اجرایی
  - PostgreSQL: `pg_dump` (قالب custom) با یافتن خودکار فایل اجرایی
  - Redis: اجرای `SAVE` و کپی فایل `dump.rdb`
  - MongoDB: `mongodump` (در صورت نصب MongoDB Database Tools)
- **مانیفست SHA-256 (برای صورت‌جلسه)** — پس از هر کپی فایل یا بکاپ، سه فایل در پوشهٔ مقصد ساخته می‌شود: `manifest.txt` (گزارش قاب‌بندی‌شده و قابل چاپ با مهر ۱۸۱، خلاصهٔ اجرا، کارت هر دیتابیس، بلوک سازگار با `sha256sum -c` و هش خود مانیفست)، `manifest.md` (قابل نمایش در GitHub) و `manifest.json` (ساختاریافته)
- تست اتصال مستقیم به دیتابیس
- تنظیمات قابل شخصی‌سازی (پورت‌های سفارشی، به‌روزرسانی خودکار)
- پروفایل دیتابیس‌های ذخیره‌شده
- آیکون در سینی سیستم با منوی سریع

## نحوه اجرا
### نسخه آماده
از صفحه [Releases](https://github.com/iranacc/DatabaseFinder/releases) یکی از دو نسخه را دریافت کنید:

- **DatabaseFinder-Light.exe:** نسخه سبک؛ نیازمند .NET 8 Desktop Runtime برای Windows x64.
- **DatabaseFinder.exe:** نسخه کامل و مستقل برای Windows x64؛ همراه با .NET و بدون نیاز به نصب جداگانه آن.

### بیلد از سورس
```bash
dotnet build DatabaseFinder/DatabaseFinder.csproj
```

## ساختن نسخه اجرایی مستقل
```bash
dotnet publish DatabaseFinder/DatabaseFinder.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o Release
```

## ورژن‌بندی
تگ‌ها برای نسخه‌های مختلف استفاده می‌شوند (مثال: `v1.8.0`).

## بررسی فنی

دستور `dotnet run --project tools/UiChecks -c Release -- ui-checks` را روی ویندوز دارای .NET 8 SDK اجرا کنید. بررسی‌ها شامل کامل بودن ترجمه‌ها، پارامترهای پیام‌ها، هر دو زبان، تغییر زبان با حفظ انتخاب‌ها، جست‌وجوی فرمت‌ها، انتخاب پسوند و اسکن فایل‌های مصنوعی است. تصاویر فرم‌ها نیز برای بازبینی ظاهری تولید می‌شوند. این بررسی‌ها بکاپ یا بازیابی دیتابیس واقعی انجام نمی‌دهند.
