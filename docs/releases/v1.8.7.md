# Database Finder v1.8.7

## فارسی

- **بکاپ بدون پسورد sa:** وقتی لاگین SQL ناموفق است (پسورد `sa` ندارید یا `sysadmin` نیستید)، بخش «کپی فایل‌ها» دیگر متوقف نمی‌شود؛ مسیر فایل‌های `MDF/LDF` از روی رجیستری و سرویس SQL پیدا شده و با همان VSS قبلی کپی می‌شود. بعد فایل‌ها را در آزمایشگاه خودتان `Attach` کنید. بکاپ منطقی (`BACKUP DATABASE`) همچنان پسورد می‌خواهد و حالا پیامش صریحا همین را می‌گوید.
- **یافتن پسورد ذخیره‌شده (دستی):** دکمه «یافتن پسورد ذخیره‌شده» در فرم بکاپ/کپی — عمدا اتوماتیک نیست چون کند است. فقط پوشه‌های مشکوک (محک/هلو/پارسیان و...) و فایل‌های کوچک کانفیگ را می‌گردد و نتیجه را با تایید شما در پروفایل ذخیره می‌کند.
- **sysadmin اضطراری (دستی):** دکمه قرمز «sysadmin اضطراری» — فقط با Administrator، با تایید دو مرحله‌ای. سرویس را در حالت تک‌کاربره (`/mSQLCMD`) ری‌استارت کرده و کاربر ویندوزی فعلی را `sysadmin` می‌کند؛ هر مرحله در لاگ و مانیفست (اقدام تهاجمی ماده ۱۸۱) ثبت می‌شود. مسیر اصلی همچنان غیرتهاجمی است.

## English

- **Backup without sa password:** when SQL login fails (no `sa` password / no `sysadmin`), "Copy files" no longer stops — `MDF/LDF` paths are resolved from the registry and the SQL service and copied with the existing VSS flow. Attach them later in your lab. Logical backup (`BACKUP DATABASE`) still needs credentials and now says so explicitly.
- **Find saved password (manual):** a "Find saved password..." button in backup/copy forms — deliberately NOT automatic (slow/noisy). It scans only vendor-suspect folders (Mahak/Holoo/Parsian...) and small config files, then saves to the profile only with your confirmation.
- **Emergency sysadmin (manual):** a red "Emergency sysadmin..." button — Administrator only, double-confirmed. Restarts the service in single-user mode (`/mSQLCMD`) and grants the current Windows user `sysadmin`; every step is logged for the Art.181 case file. The default path stays non-invasive.

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.
