# Database Finder v1.8.3

## فارسی

- رفع خطای «File discovery failed: DLL was not found» هنگام اتصال به SQL Server: در نسخه‌های ۱.۸.۱ و ۱.۸.۲ فایل‌های بومی برنامه (از جمله `Microsoft.Data.SqlClient.SNI.dll`) هنگام انتشار تک‌فایلی به‌صورت فایل جدا کنار فایل اجرایی قرار می‌گرفتند و چون فقط خود exe در GitHub منتشر می‌شد، این DLL‌ها پیدا نمی‌شدند. حالا همهٔ فایل‌های بومی داخل همان exe بسته می‌شوند (همان رفتار نسخهٔ ۱.۸) و «کشف فایل»/کپی بکاپ برای SQL Server دوباره کار می‌کند.
- این انتشار با `IncludeNativeLibrariesForSelfExtract` و `IncludeAllContentForSelfExtract` در خود پروژه ثبت شده تا در انتشارهای آینده هم تکرار نشود.

**فایل‌های اجرایی:** `DatabaseFinder-Light.exe` نسخه سبک و نیازمند .NET 8 Desktop Runtime برای Windows x64 است. `DatabaseFinder.exe` نسخه کامل و مستقل با .NET داخلی است. فایل `SHA256SUMS.txt` برای بررسی صحت هر دو دانلود ضمیمه شده است.

## English

- Fixed "File discovery failed: DLL was not found" when connecting to SQL Server: in v1.8.1 and v1.8.2 the single-file publish left native libraries (including `Microsoft.Data.SqlClient.SNI.dll`) as separate files next to the executable, and because only the exe itself is published on GitHub those DLLs were never found. All native libraries are now bundled inside the exe (matching v1.8 behaviour), so "file discovery"/backup copy works again for SQL Server.
- The `IncludeNativeLibrariesForSelfExtract` and `IncludeAllContentForSelfExtract` options are now set in the project file so future releases publish correctly.

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.

- The published standalone exe starts correctly from an empty folder (only the exe present).
