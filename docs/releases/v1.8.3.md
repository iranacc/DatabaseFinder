# Database Finder v1.8.3

## فارسی

- اصلاح بسته‌بندی نسخهٔ تک‌فایلی: همهٔ فایل‌های بومی (از جمله کتابخانهٔ اتصال به SQL Server) داخل خود فایل اجرایی قرار می‌گیرند؛ دیگر نیازی به فایل جدا کنار exe نیست و اتصال و «کشف فایل» SQL Server بدون خطا کار می‌کند.
- گزینه‌های بسته‌بندی در فایل پروژه ثبت شده تا در انتشارهای آینده نیز درست بماند.

**فایل‌های اجرایی:** `DatabaseFinder-Light.exe` نسخه سبک و نیازمند .NET 8 Desktop Runtime برای Windows x64 است. `DatabaseFinder.exe` نسخه کامل و مستقل با .NET داخلی است. فایل `SHA256SUMS.txt` برای بررسی صحت هر دو دانلود ضمیمه شده است.

## English

- Fixed single-file packaging: all native libraries (including the SQL Server connection library) are now bundled inside the executable itself, so no separate files are needed next to the exe and SQL Server file discovery works without errors.
- The packaging options are set in the project file so future releases stay correct.

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.
