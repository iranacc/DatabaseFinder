# Database Finder v1.8.1

## فارسی

- بهبود کارایی تشخیص پورت‌ها: جداسازی پورت→PID حالا با یک بار اجرای netstat انجام می‌شود (پیش از این برای هر پورت یک بار اجرا می‌شد).
- تست اتصال برای دریافت نسخه به حالت غیرمسدودکننده تبدیل شد؛ رابط در شبکه‌های کند دیگر یخ نمی‌زند و ردیف‌ها با پایان تست به‌روز می‌شوند. افزودن مهلت اتصال ۵ ثانیه‌ای.
- اصلاح نگاشت نسخه به ردیف‌های جدول: به‌جای تطبیق نام+پورت، از شاخص استفاده می‌شود تا نسخه در ردیف اشتباه ننشیند.
- کاهش تشخیص اشتباه MySQL: فقط فرآیندهای mysqld/mysql شناسایی می‌شوند، نه هر فرآیندی که در نامش «mysql» باشد.
- افزودن لاگ فنی خطاهای بلعیده‌شده (`%AppData%\DatabaseFinder\debug.log`) در تنظیمات/پروفایل‌ها، شناسایی، مانیفست و Shadow Copy.
- افزودن فایل راه‌حل (solution) برای ساخت یکپارچه‌ای همه پروژه‌ها.

**فایل‌های اجرایی:** `DatabaseFinder-Light.exe` نسخه سبک و نیازمند .NET 8 Desktop Runtime برای Windows x64 است. `DatabaseFinder.exe` نسخه کامل و مستقل با .NET داخلی است. فایل `SHA256SUMS.txt` برای بررسی صحت هر دو دانلود ضمیمه شده است.

## English

- Port detection performance: the port→PID map is now built with a single netstat run instead of one per port.
- Version probing moved off the UI thread; the interface no longer freezes on slow networks, and rows update as tests finish. Added a 5-second connect timeout.
- Version results are now matched to grid rows by index instead of name+port, so a version can no longer land in the wrong row.
- Fewer MySQL false positives: only mysqld/mysql processes are detected, not any process whose name contains "mysql".
- Added a technical log for swallowed errors (`%AppData%\DatabaseFinder\debug.log`) across settings/profiles, detection, the manifest, and Shadow Copy.
- Added a solution file so all projects build in one command.

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.
