# Database Finder v1.8.6

## فارسی

- **به‌روزرسانی داخلی:** برنامه هنگام اجرا آخرین نسخه را از ریلیزهای GitHub (مخزن iranacc/DatabaseFinder) می‌خواند و با نسخهٔ خودش مقایسه می‌کند؛ اگر نسخهٔ جدیدتری موجود باشد، بالای صفحه لینک «نسخهٔ جدید … آماده است — به‌روزرسانی» ظاهر می‌شود و به منوی سینی ویندوز هم مورد «بررسی به‌روزرسانی» اضافه شده است. با کلیک، فایل نصب جدید با نمایش درصد پیشرفت دانلود می‌شود، صحت فایل با SHA-256 از فایل `SHA256SUMS.txt` همان ریلیز راستی‌آزمایی می‌شود و سپس به‌صورت خودکار جایگزین فایل اجرایی قبلی شده و برنامه دوباره راه‌اندازی می‌شود. نسخهٔ مناسب خودکار انتخاب می‌شود: اگر نسخهٔ سبک (Light) در حال اجراست فایل سبک، و اگر نسخهٔ مستقل در حال اجراست فایل مستقل دانلود می‌شود.
- **عنوان پنجرهٔ واقعی:** عدد عنوان برنامه دیگر ثابت نیست و نسخهٔ واقعی فایل اجراییِ در حال اجرا را نشان می‌دهد.

## English

- **In-app self-update:** on startup the app reads the latest release from the GitHub repository (iranacc/DatabaseFinder) and compares it with its own version; when a newer one exists an "Update" link appears in the header and a "Check for updates" item is added to the tray menu. Clicking it downloads the update with a live percentage, verifies the file's SHA-256 against the release `SHA256SUMS.txt`, then swaps the executable and restarts automatically. The right variant is picked on its own: run the Light build → the Light asset is downloaded; run the standalone build → the standalone asset.
- **Honest title bar:** the window title now shows the actual version of the running executable instead of a fixed number.

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.
