# Database Finder v1.8.12

## فارسی

### ظاهر و تجربهٔ کاربری

- حالت تاریک اختیاری به تنظیمات اضافه شد و رنگ پس‌زمینه، پنل‌ها، دکمه‌ها، ورودی‌ها، درخت‌ها و جدول‌ها را یکپارچه تغییر می‌دهد.
- حالت تاریک پس از ذخیرهٔ تنظیمات بدون خروج از برنامه روی صفحهٔ اصلی اعمال می‌شود.
- برای بخش‌های اصلی برنامه آیکن اضافه شد: دیتابیس‌های فعال، جست‌وجوی فایل، اسکن شبکه، پروفایل‌ها و تنظیمات.
- جدول اصلی ستون مستقل `وضعیت` دارد و وضعیت‌های آنلاین، سرویس متوقف، فایل آفلاین و فایل بکاپ را با متن پررنگ و رنگ پس‌زمینهٔ جدا نمایش می‌دهد.
- چهار کارت خلاصه در بالای جدول اضافه شد: کل نتایج، آنلاین، فایل‌های پیدا‌شده و انتخاب‌شده.
- پنل جزئیات از یک خط متن به پنل چندخطی شامل نام، نوع، وضعیت، نسخه، اتصال/سرویس و مسیر تبدیل شد.
- دکمهٔ کپی مسیر برای موارد دارای مسیر فایل اضافه شد.
- حالت خالی صفحهٔ اصلی پیام راهنما نمایش می‌دهد و دیگر یک جدول سفید بدون توضیح دیده نمی‌شود.
- برای دکمه‌های فرم‌ها Tooltip خودکار اضافه شد.
- میانبرهای صفحهٔ اصلی اضافه شد: `F5` اسکن مجدد، `Ctrl+A` انتخاب همه، `Ctrl+Shift+A` لغو انتخاب و `Ctrl+C` کپی لیست.
- حداقل اندازه و فاصله‌گذاری صفحهٔ اصلی برای پنجره‌های کوچک و نمایشگرهای High-DPI بهبود یافت.

### سرویس‌ها و SQL Server

- وضعیت Startup Type سرویس‌های دیتابیس خوانده می‌شود.
- هنگام ورود اولیه، اگر SQL Server نصب اما متوقف باشد، هشدار واضح نمایش داده می‌شود و امکان Start همان سرویس وجود دارد.
- برای سرویس `Disabled` گزینهٔ جداگانهٔ `Enable and start` اضافه شد؛ با تأیید کاربر Startup Type به `Manual` تغییر می‌کند.
- پس از Start موفق سرویس، اسکن خودکار دوباره اجرا می‌شود.
- اگر تشخیص اصلی ردیف سرویس را نسازد، بررسی مستقیم سرویس‌های Windows به‌عنوان fallback هشدار را فعال می‌کند.
- سرویس‌های متوقف در نوار وضعیت نیز هشدار پایدار دارند تا پیام پشت پنجره پنهان نشود.
- Instanceهای پیش‌فرض و نام‌گذاری‌شدهٔ SQL Server با نام سرویس واقعی پشتیبانی می‌شوند.

### کپی و بکاپ

- کپی فیزیکی و بکاپ native نوار پیشرفت واقعی دارند.
- پیشرفت بر اساس تعداد آیتم‌های واقعاً پردازش‌شده به‌روزرسانی می‌شود، نه صرفاً حالت چرخشی.
- بعد از کپی، تعداد فایل موفق، ناموفق و حجم پردازش‌شده نمایش داده می‌شود.
- بعد از بکاپ، تعداد موفق، ناموفق و حجم خروجی تولیدشده نمایش داده می‌شود.
- چیدمان مشترک فرم‌های کپی و بکاپ برای قرارگیری نوار پیشرفت اضافه شد.

### تغییرات فنی

- `DarkMode` به تنظیمات ذخیره‌شده اضافه شد.
- تم و Tooltip به `AppForm` منتقل شد تا روی فرم‌های مختلف یکسان اعمال شود.
- نسخهٔ ابزار مانیفست و اسمبلی به `1.8.12` افزایش یافت.
- checksum فایل‌های Release به‌روزرسانی شد.

## English

### UI and user experience

- Added optional dark mode to Settings with consistent colors for forms, panels, buttons, inputs, trees and grids.
- Dark mode is applied to the main screen immediately after saving Settings.
- Added icons to the main navigation areas: running databases, file search, network scan, profiles and settings.
- Added a dedicated `Status` column with distinct styling for Online, Service stopped, Offline file and Backup file.
- Added four summary cards: total results, online, files found and selected.
- Rebuilt the details area into a multi-line panel showing name, engine, status, version, connection/service and path.
- Added a copy-path action for file-backed results.
- Added an empty-results state with guidance instead of a blank table.
- Added automatic tooltips to form buttons.
- Added main-screen shortcuts: `F5` rescans, `Ctrl+A` selects all, `Ctrl+Shift+A` clears selection and `Ctrl+C` copies the list.
- Improved the main layout minimum size and spacing for small windows and high-DPI displays.

### Services and SQL Server

- Read and display the Windows service Startup Type.
- On first launch, warn when an installed SQL Server service is stopped and offer to start that specific service.
- Added a separate `Enable and start` action for Disabled services; it changes Startup Type to `Manual` only after confirmation.
- Automatically rescan after a successful service start.
- Added a direct Windows-service fallback check so the startup warning still works when the normal detector does not produce a row.
- Keep a persistent stopped-service warning in the main status area so it cannot be hidden behind another window.
- Support both default and named SQL Server instances using their real Windows service names.

### Copy and backup operations

- Added real progress bars to physical copy and native backup forms.
- Progress is based on actually processed items instead of an indeterminate animation.
- Copy completion now reports successful files, failed files and processed bytes.
- Backup completion now reports successful items, failed items and produced bytes.
- Shared operation layout now supports the progress bar consistently across copy and backup forms.

### Technical changes

- Persisted the `DarkMode` setting.
- Centralized theme and tooltip application in `AppForm`.
- Bumped manifest and assembly version metadata to `1.8.12`.
- Updated Release checksums.
