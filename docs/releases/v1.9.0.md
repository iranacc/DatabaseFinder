# Database Finder v1.9.0

## فارسی

- **مدرن‌سازی کامل رابط کاربری (Modern UI/UX):**
  - **تایپوگرافی مدرن فارسی با فونت وزیرمتن (Vazirmatn):** تعبیه (Embed) فایل‌های فونت رسمی وزیرمتن به صورت درون‌برنامه‌ای، بدون نیاز به نصب هرگونه فونت روی سیستم کاربر. تمام عناوین، جدول‌ها، دکمه‌ها و فرم‌ها با بالاترین خوانایی در مانیتورهای High-DPI رندر می‌شوند.
  - **سیستم کارت‌های لایه‌ای (ModernCard):** بازطراحی فرم‌ها بر اساس کارت‌های گوشه‌گرد با شعاع ۸ پیکسل و حاشیه ظریف برای تفکیک بصری شیک و چشم‌نواز.
  - **پالت رنگی هماهنگ و زنده (Slate / Modern Indigo):** به‌کارگیری پالت رنگی استاندارد روز (مشابه ویندوز ۱۱ و Tailwind) شامل رنگ‌های خنثی سربی، آبی اکسنت مدرن و نشانگرهای رنگی وضعیت.
  - **ترمینال زنده لاگ (Dark Live Terminal):** جعبه لاگ با پس‌زمینه تیره مدرن، فونت Monospace و دکمه تک‌کلیک «کپی لاگ» برای انتقال سریع لاگ‌ها به کلیپ‌بورد.
  - **چیدمان جدید فرم کپی و بکاپ (OperationLayout):** سازمان‌دهی دکمه‌ها در پنل دسته‌بندی‌شده، حذف اسکرول‌بار اضافه، فضای تنفس و هدر یکپارچه مسیر مقصد.
- **جست‌وجوی پوشه انتخابی:** امکان اسکن مستقیم یک پوشه سفارشی به جای اسکن کل درایوها در فرم کپی فایل‌ها.
- **اصلاح واژگان زبان فارسی:** جایگزینی واژه استاندارد «انتخاب مسیر...» به جای «بگرد...».

## English

- **Complete UI/UX Modernization (Modern WinForms Native):**
  - **Vazirmatn Persian Typography:** Embedded official Vazirmatn Regular & Bold fonts via `PrivateFontCollection`. Persian text renders with crisp modern baseline across high-DPI displays with automatic fallback to Segoe UI Variable for English.
  - **Rounded Surface Cards (`ModernCard`):** Refactored form layouts using 8px rounded cards with subtle borders and clean elevation.
  - **Cohesive Modern Palette:** Transitioned from legacy flat colors to a cohesive Slate/Indigo color token system inspired by Windows 11 Fluent and Tailwind CSS.
  - **Live Terminal Log:** Terminal-styled dark slate log panel with Monospace typography and one-click "Copy Log" clipboard action.
  - **Refined Layout Architecture (`OperationLayout`):** Clean separation of destination header card, database file tree, organized tool sidebar, terminal log, and bottom action bar.
- **Target Folder Sweep:** Direct folder selection sweep in the file copy dialog alongside whole-drive deep sweeps.
- **Localization Refinement:** Updated Persian folder picker button from "بگرد..." to "انتخاب مسیر...".

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.
