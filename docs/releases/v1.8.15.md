# Database Finder v1.8.15

## فارسی

- **رفع باگ «نامرئی بودن تیک» در جدول نتایج جست‌وجوی فایل (آفلاین):** در ستون «انتخاب» جدول نتایج، علامت تیک در ردیف‌های پیدا‌شده کشیده نمی‌شد (ستون خالی به نظر می‌رسید) و عملاً نمی‌شد فایل‌ها را انتخاب کرد. علت این بود که ردیف‌های دستیِ جدول ارتفاع کوتاه‌تری داشتند و با پدینگ تم، جای رسم چک‌باکس خالی (۰×۰) محاسبه می‌شد. حالا ارتفاع ردیف‌ها درست تنظیم می‌شود و تیک در همهٔ ردیف‌ها نمایش داده شده و انتخاب ثبت می‌شود.

## English

- **Fixed the invisible selection checkbox in the offline "File search" results grid:** the checkbox in the "Select" column was not being painted, so found files could not be selected. The manually-added result rows were shorter (29 px) than the theme's padded cells, which made the checkbox render area empty (0×0). Rows are now sized correctly so the checkbox always draws and the selection works.

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.
