# Database Finder v1.8.5

## فارسی

- **رفع باگ مقصد بکاپ:** فهرست بکاپ فقط یک بار هنگام باز شدن پنجره ساخته می‌شد؛ اگر مقصد را تغییر می‌دادید، فایل‌ها واقعاً به پوشهٔ پیش‌فرض (`C:\DatabaseFinder\Backup`) می‌رفتند ولی گزارش و مانیفست در مقصد جدید (خالی) ساخته می‌شد. حالا با تغییر مقصد، فهرست خودکار دوباره ساخته می‌شود (تیک‌های انتخابی حفظ می‌شوند) و بکاپ واقعاً به همان پوشهٔ انتخابی می‌رود.
- **گزینه‌های بکاپ SQL Server:** فشرده‌سازی (COMPRESSION)، تأیید صحت پس از اتمام (VERIFYONLY) و Checksum هنگام نوشتن روی رسانه (CHECKSUM) — مثل خود SSMS، با مقادیر پیش‌فرض معقول.
- **مانیفست کامل و زیبا:** هر بکاپ حالا سه فایل می‌سازد: `manifest.txt` (قاب‌بندی‌شده با سربرگ «مهر» لوگوی ۱۸۱، خلاصهٔ اجرا، کارت هر دیتابیس با گزینه‌ها/زمان‌ها/وضعیت/نسبت فشرده‌سازی، جدول هش فایل‌ها و بلوک سازگار با `sha256sum -c manifest.txt`)، `manifest.md` (قابل نمایش در GitHub) و `manifest.json` (ساختاریافته)؛ نسخهٔ سرویس‌ها با پرس‌وجوی زنده ثبت و هش خود فایل در خودش درج می‌شود.
- **مهر مادهٔ ۱۸۱:** بالای مانیفست «مهر» بزرگ شمارهٔ ۱۸۱ (مادهٔ ۱۸۱ قانون مالیات‌های مستقیم) همراه با «TAX 181 ARTICLE . MSAM Group» چاپ می‌شود تا خروجی به‌عنوان دادهٔ استخراج‌شدهٔ ماشین‌خوان قابل شناسایی باشد.
- **فهرست دیتابیس‌ها:** دابل‌کلیک روی ستون «تعداد دیتابیس‌ها» در صفحهٔ اصلی، فهرست نام دیتابیس‌های همان سرویس را باز می‌کند.

**فایل‌های اجرایی:** `DatabaseFinder-Light.exe` نسخه سبک و نیازمند .NET 8 Desktop Runtime برای Windows x64 است. `DatabaseFinder.exe` نسخه کامل و مستقل با .NET داخلی است. فایل `SHA256SUMS.txt` برای بررسی صحت هر دو دانلود ضمیمه شده است.

## English

- **Fixed backup destination bug:** the backup plan was built only once when the window opened; changing the destination silently left the plan pointing at the default folder (`C:\DatabaseFinder\Backup`) while the log and manifest pointed at the new (empty) folder. The plan is now rebuilt automatically whenever the destination changes (checked databases are preserved), and backups really land in the folder you selected.
- **SQL Server backup options:** compression (COMPRESSION), verify on completion (VERIFYONLY) and checksum before writing to media (CHECKSUM) — SSMS-style, with sane defaults.
- **Rich, prettier manifest:** every backup now produces three files — `manifest.txt` (a framed layout headed by a 181 "stamp", with an execution summary, a per-database card showing options/timing/status/compression ratio, a file-hash table and a `sha256sum -c manifest.txt`-compatible block), `manifest.md` (GitHub-ready) and `manifest.json` (structured); server versions are probed live and the manifest carries its own SHA-256.
- **Article 181 stamp:** a large 181 logo (Article 181 of the Iranian Direct Tax Law) with the caption `TAX 181 ARTICLE . MSAM Group` heads every manifest, marking the output as machine-readable extracted data.
- **Database list:** double-clicking the "# Databases" column on the main page opens the list of database names for that service.

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.
