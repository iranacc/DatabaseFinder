# Database Finder v1.8.0

## فارسی

- بازطراحی صفحه اصلی با منوی کناری، جدول خواناتر، انتخاب همه/هیچ و نمایش جزئیات و مسیر.
- افزودن زبان انگلیسی و تغییر زبان فارسی/انگلیسی بدون از دست رفتن نتایج و تیک‌های انتخاب‌شده؛ ذخیره زبان انتخابی.
- پنجره مستقل انتخاب فرمت با جست‌وجو، ۱۱ گروه بازشدنی و انتخاب مستقل هر یک از ۲۸ پسوند.
- بهبود چیدمان پنجره‌های اسکن فایل، کپی، بکاپ، تنظیمات، کوئری، شبکه، پروفایل و جزئیات.
- ترجمه پیام‌ها و گزارش‌های عملیاتی با حفظ نام فایل‌ها، مسیرها و نام دیتابیس‌ها.
- اصلاح باز شدن پنجره کوئری SQLite بدون پورت شبکه.
- اصلاح افزودن نتایج آفلاین به جدول اصلی: فقط ردیف‌های تیک‌خورده اضافه می‌شوند.

**فایل‌های اجرایی:** `DatabaseFinder-Light.exe` نسخه سبک و نیازمند .NET 8 Desktop Runtime برای Windows x64 است. `DatabaseFinder.exe` نسخه کامل و مستقل با .NET داخلی است. فایل `SHA256SUMS.txt` برای بررسی صحت هر دو دانلود ضمیمه شده است.

## English

- Redesigned main window with sidebar navigation, clearer results, select all/none, and a details/path panel.
- Persian / English switching with a saved preference; scan results and checked rows survive language changes.
- Dedicated searchable format picker with all 11 expandable groups and individual selection of 28 extensions.
- Updated layouts for disk search, copy, native backup, settings, queries, network scanning, profiles and details.
- Localized application messages and operational logs; file paths, database names and structured manifest fields remain unchanged.
- Fixed the SQLite query window opening with no network port.
- Adding offline results to the main window now includes only checked rows.

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.

## Validation

- Release build and Windows x64 single-file Light and standalone publish.
- Automated translation, UI, language-switch preservation, format selection and synthetic disk-scan checks.
- Visual inspection of Persian and English layouts, including the main and disk-search windows at their minimum sizes.
- Native database backup and restore operations were not exercised as part of this UI release.
