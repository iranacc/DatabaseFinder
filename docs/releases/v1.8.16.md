# Database Finder v1.8.16

## فارسی

- **اصلاح اعتبارسنجی بکاپ‌های SQL Server:** پشتیبانی رسمی از استاندارد Microsoft Tape Format (MTF) با امضای TAPE تا تمام بکاپ‌های واقعی (.bak) پیدا شده و فایل‌های متفرقه با پسوند مشابه رد شوند.
- **رفع قفل متقابل (Deadlock):** رفع مشکل فریز در پروسس‌های کمکی اضطراری با پردازش ناهمگام استریم‌های خروجی.
- **روان‌سازی کامل رابط کاربری:** اجرای اسکن دیتابیس در پس‌زمینه بدون کوچک‌ترین فریز یا قفل شدن پنجره.
- **محافظت در برابر Junction Points:** جلوگیری از ورود به حلقه‌های بی‌پایان در اسکن هارددیسک و اعمال سقف عمق ۲۴ سطح.
- **اصلاح بروزرسانی جدول:** همگام‌سازی اطلاعات زنده دیتابیس‌ها با شیء اصلی به جای اندیس ردیف در هنگام سورت جدول.
- **امنیت دسترسی و رمز عبور:** رمزنگاری پسوردهای پروفایل‌ها با پروتکل ویندوزی DPAPI.
- **پایداری حافظه و چرخش لاگ:** محدودیت هوشمند واکشی کوئری تا ۵۰۰۰ سطر و چرخش فایل لاگ خطاها در سقف ۵ مگابایت.
- **پویاسازی نسخه مانیفست:** درج خودکار شماره نسخه جاری برنامه در مانیفست‌های رسمی ماده ۱۸۱.

## English

- **SQL Server .bak validation fix:** added full Microsoft Tape Format (MTF) header validation with `TAPE` signature, ensuring legitimate native SQL backups are properly discovered during disk scans while filtering out non-database files.
- **Process Redirection Deadlock resolved:** fixed synchronous stream reading deadlock when executing emergency tools with asynchronous stdout/stderr pipeline.
- **Non-blocking UI:** moved database detection off the UI thread to background worker, keeping the main dashboard fully responsive.
- **Junction point protection:** skipped `ReparsePoint` directories and applied depth limits (24 levels) to disk traversal.
- **Grid row index sync:** mapped live database counts and versions to items by reference instead of numeric row indices, preventing incorrect data mapping when columns are sorted.
- **Secure password storage:** encrypted database credentials in `profiles.json` using Windows DPAPI.
- **Resource safety:** capped interactive query execution at 5,000 rows to prevent `OutOfMemoryException`, and added 5 MB log rollover.
- **Dynamic manifest version:** manifest reports now dynamically display the true running assembly version.

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.
