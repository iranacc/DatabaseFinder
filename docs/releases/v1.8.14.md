## English

- **Fixed offline file-search selection:** checking the found items in the "File search" results grid previously did not stick (clicking the checkbox or the row did not persist the value). Now a single click toggles and commits the checkbox, and "Copy files" / "Merge into main list" act on the actually-selected rows.
- **Dropped the English line from the Persian reports:** the sentence `TAX 181 ARTICLE . MSAM Group` is no longer printed in the Persian printable reports (case report and network-scan report). The 181 logo and the technical manifest (txt/md/json) stamp remain unchanged.
- **This build also ships the v1.8.13 manual-folder copy hardening** (no runaway link traversal, VSS for locked manual-folder files, explicit error for a missing folder, and a real free-space estimate).

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.
