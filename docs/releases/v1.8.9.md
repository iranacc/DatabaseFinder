# Database Finder v1.8.9

## فارسی

- **چرخش به نامه/کپی: همراه‌کردن ژورنال‌های SQLite:** فایل‌های `-wal` و `-shm` یک دیتابیس اس‌کیوالایت حالا در همه مسیرهای کپی (کپی از فرم کپی، اسکن آفلاین، کپی فایل از منوی راست‌کلیک) همراه فایل اصلی کپی می‌شوند تا اگر دیتابیس به‌صورت تمیز بسته نشده باشد، داده‌ها کامل برداشت شوند (هر سه فایل جداگانه هش veriy گرفته و در مانیفست ثبت می‌شوند).
- **گزارش فارسی چاپی (صورتجلسه):** هم‌زمان با هر مانیفست، یک فایل `report.html` فارسی/راست‌به‌چپ ساخته می‌شود (قابل باز شدن با Word/Converter به PDF) شامل مشخصات پرونده، خلاصه اجرا، جدول دیتابیس‌ها، جدول تطابق فایل‌ها با هش مبدأ و جای امضای مأمور و نماینده مؤدی. دکمه «گزارش فارسی» در هر دو فرم (نسخه پشتیبان و کپی) اضافه شد. این گزارش فقط نمای خلاصه است؛ ارزش اثباتی از manifest.txt/json می‌آید.
- **جست‌وجوی عمیق درایوها (با رضایت کاربر):** در حالت بدون لاگین، با تأیید کاربر، کل درایوها برای فایل‌های دیتابیس اسکن می‌شوند (fallback بدون احراز هویت).
- **دکمه دستی «جست‌وجوی عمیق درایوها»:** در فرم کپی، اسکن عمیق را می‌توان دستی هم اجرا کرد؛ نتایج جدید بدون تکرار (بر اساس پوشه و نام) مرج می‌شوند.
- **سرنخ دیتای زنده:** ستون‌های وضعیت قفل (فقط در حال استفاده/خالی) و تاریخ آخرین تغییر روی درخت کپی افزوده شد؛ دیتابیس‌های زنده اول لیست می‌شوند و تولتیپ جزئیات را نشان می‌دهد.
- **رفع کرش صفحه کپی:** هم‌عملیات بومی Restart Manager حذف و با پروب خالص دات‌نتی جایگزین شد (بدون نمایش نام پروسس). علاوه بر آن، یک نگهبان خطای سراسری در `Program.cs` اضافه شد که هر خطای فرمانـیافته را در لاگ (`%AppData%\DatabaseFinder\debug.log`) ثبت و به‌صورت کادر به کاربر نمایش می‌دهد.
- **ریست `sa` دوحالته:** (a) ریست روی‌سایت: تعیین نسخه، جستجوی محل سرویس و فلاگ `-m`؛ با تأیید تهاجمی، پسورد جدید کوتاه/قوی تنظیم و دیتابیس‌ها سپس با آن کپی می‌شوند. (b) دکمه «اسکریپت ریست آزمایشگاهی» که یک `LabReset-Sa.bat` + `LabReadme.txt` می‌سازد تا در محیط آزمایشگاهی/دیسک ۱۰ اکسترنال انجام شود.
- **راستی‌آزمایی مبدأ و مقصد:** کپی فایلی حالا بعد از کپی، SHA-256 مبدأ با مقصد مقایسه می‌شود؛ چک‌باکس «راستی‌آزمایی کپی»، بررسی فضای دیسک مقصد پیش از شروع، و بخش «acquisition» در هر سه مانیفست (txt/md/json) با وضعیت MATCH/DIFF با هش مبدأ و مقصد افزوده شد.
- **حالت پرتابل:** قرار دادن فایل `portable.txt` کنار فایل اجرایی، همه تنظیمات/پروفایل/لاگ و پوشه دانلود آپدیت را در پوشه `Data` کنار برنامه نگه می‌دارد تا هیچ ردپایی روی سیستم مؤدی باقی نماند (نشان «Portable» در عنوان پنجره).
- **مشخصات پرونده (اختیاری):** بعد از هر عملیات (یا با دکمه مانیفست) یک کادر اختیاری پرسیده می‌شود تا شماره پرونده/نام مأمور/شماره حکم و توضیحات در همه مانیفست‌ها ثبت شود؛ می‌توان آن را رد کرد (فقط یک بار در هر فرم پرسیده می‌شود).
- **تشخیص اینستنس‌های خاموش SQL:** اینستنس‌های سرویس‌هایی که اجرا نمی‌شوند از رجیستری و WMI شناسایی و مسیر دیتابیس‌هایشان مستقیماً (بدون VSS) کپی می‌شود؛ در شمارش skips حساب می‌شوند اما در مانیفست ثبت و با یک پیام راهنما مشخص می‌شوند.

## English

- **SQLite WAL/SHM companions bundled:** in every copy path (copy page, offline scan, right-click file copy) the `-wal`/`-shm` journal files of a SQLite database are copied together with the main file, so data is complete even if the database was not shut down cleanly (each file gets its own verified hash in the manifest).
- **Persian printable case report (minute of proceedings):** every manifest now also produces a right-to-left Persian `report.html` (opens in Word / convertible to PDF) with case info, run summary, per-database table, file-match table with source hashes, and signature/date areas for the officer and the taxpayer representative. A "Persian report" button was added to both forms. The report is only a presentation aid; evidentiary value stays in manifest.txt/json.
- **Deep drive sweep (with user consent):** in the no-login fallback, full drives can be scanned for database files after explicit confirmation.
- **Manual deep-search button** on the copy form; new findings are merged with dedupe keyed by folder+name.
- **Live-DB hints:** lock state column (in-use/empty) and last-modified dates on the copy tree; live databases sort first, tooltips show details.
- **Copy-page crash fix:** native Restart Manager interop removed and replaced by a pure .NET lock probe (process name no longer shown). A global crash guard in `Program.cs` now logs and surfaces any unhandled exception (`%AppData%\DatabaseFinder\debug.log`).
- **Two-mode `sa` reset:** (a) on-site invasive reset — detects version, locates the service and `-m` flag, sets a fresh strong password after explicit acknowledgment, then copies databases using it; (b) "lab reset script" button that emits `LabReset-Sa.bat` + `LabReadme.txt` to run offline on an external disk / lab machine.
- **Source↔destination verification:** file copy now SHA-256-verifies destination against source; a "verify copy" checkbox, a pre-copy free-space check, and an `acquisition` section (MATCH/DIFF with source and dest hashes) in all three manifests.
- **Portable mode:** placing a `portable.txt` marker next to the executable keeps settings/profiles/debug log and the download folder in a local `Data` folder, leaving no traces on the inspected system ("Portable" shown in the title bar).
- **Optional case-file info dialog (asked once per form, skippable):** case number / officer / warrant number / notes go into all manifests.
- **Stopped SQL instances detected** from registry + WMI (non-running services); their database files are copied directly (no VSS), listed as skips with a hint message, and still recorded in the manifest.

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.
