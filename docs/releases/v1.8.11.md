# Database Finder v1.8.11

## فارسی

- بررسی SHA-256 قبل از نصب آپدیت خودکار.
- جلوگیری از انتخاب فایل اجرایی نامرتبط برای نسخه‌های Light و کامل.
- گروه‌بندی صحیح فایل‌های SQL Server شامل MDF، LDF و NDF.
- جلوگیری از روشن‌شدن سرویس‌هایی که پیش از کپی خاموش بوده‌اند.
- جلوگیری از کپی بازگشتی وقتی مقصد داخل منبع است.
- خطا اعلام‌کردن بکاپ‌هایی که خروجی معتبر تولید نمی‌کنند.
- ارسال امن آرگومان‌های ابزارهای `mysqldump`، `pg_dump` و `mongodump`.
- نمایش نام Instance در پوشه‌های کپی SQL Server و اعتبارسنجی تنظیمات خراب.
- اصلاح عنوان و فیلد هش گزارش اسکن شبکه.

## English

- Verify the downloaded updater executable with SHA-256 before replacement.
- Never fall back to an unrelated executable asset for Light or standalone builds.
- Group SQL Server MDF, LDF and NDF files correctly for physical copies.
- Restart only services that this copy operation actually stopped.
- Block recursive copies when the destination is inside the source folder.
- Fail backups that produce no valid output files.
- Pass `mysqldump`, `pg_dump` and `mongodump` arguments safely.
- Include SQL Server instance names in copy folders and normalize malformed settings.
- Correct the remote-scan report hash label and JSON field.
