## فارسی

## English

- **"Choose folder manually" fix:** the button now works in all three cases — if you clicked a group/server node or nothing is selected, it auto-finds and selects the first failed item; if files were already auto-located (e.g. no-login fallback), it asks for confirmation to override with the manual folder; and after picking the folder the database is auto-checked so it is included in the copy.

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.
