# Database Finder v1.8.2

## فارسی

- رفع باگ نسخه ۱.۸.۱: شناسایی دیتابیس‌ها دیگر بعد از اولین اسکن قفل نمی‌شود. ریشهٔ مشکل این بود که دیتابیس‌هایی که خودشان بنر نمی‌فرستند (مثل SQL Server) خواندن بنر را برای همیشه معلق نگه می‌داشتند و تست نسخه هرگز تمام نمی‌شد؛ در نتیجه همهٔ اسکن‌های بعدی ساکتانه بدون نتیجه انجام می‌شدند. حالا کل تست اتصال یک مهلت سراسری ۵ ثانیه‌ای دارد و هر بار روی Refresh دوباره تشخیص واقعی اجرا می‌شود.
- افزودن تشخیص بکاپ‌های نرم‌افزارهای حسابداری ایرانی به اسکن آفلاین: **محک** (الگوهای نام `Backup-mahak…`، `Auto-mahak…`، `BeforeUpdate…`، `FullBackup-…` و `ver…` با پسوندهای `.bak`/`.zip`)، **پارسیان** (پوشهٔ `PARSIAN.BACK`) و **هلو** (پوشهٔ `Holoo.Bak` با `.zip`/`.bak`). این پوشه‌ها به مسیرهای جست‌وجوی سریع هم اضافه شدند.
- اولویت‌بندی تطبیق در اسکن فایل: مسیر پوشه → الگوی نام فایل → پسوند.
- به‌روزرسانی مانیفست و مستندات.

**فایل‌های اجرایی:** `DatabaseFinder-Light.exe` نسخه سبک و نیازمند .NET 8 Desktop Runtime برای Windows x64 است. `DatabaseFinder.exe` نسخه کامل و مستقل با .NET داخلی است. فایل `SHA256SUMS.txt` برای بررسی صحت هر دو دانلود ضمیمه شده است.

## English

- Fixed the v1.8.1 regression where detection silently stalled: a banner read could block forever on servers that don't send an unsolicited greeting (e.g. SQL Server), leaving detection permanently "busy" so every later scan silently did nothing. The whole version probe now has a hard 5-second cap and re-detection always restarts on Refresh.
- The offline scan now recognizes backup folders of Iranian accounting packages: **Mahak** (name patterns `Backup-mahak…`, `Auto-mahak…`, `BeforeUpdate…`, `FullBackup-…` and `ver…` with `.bak`/`.zip`), **Parsian** (`PARSIAN.BACK` folder) and **Holoo** (`Holoo.Bak` folder with `.zip`/`.bak`). These folders were also added to the quick-scan roots.
- Disk matching priority is now folder path → file-name pattern → extension.
- Manifest and documentation updated.

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.
