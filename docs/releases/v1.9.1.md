# Database Finder v1.9.1

## فارسی

- **نمایش درصد و حجم پیشرفت زنده در کپی فایل‌های حجیم:**
  - جایگزینی `File.Copy` بلوکه‌شونده با موتور استریمی پرسرعت `CopyFileWithProgress` مجهز به بافر ۱ مگابایتی برای حداکثر پهنای باند I/O دیسک.
  - نمایش درصد لحظه‌ای و حجم کپی‌شده به صورت زنده در لاگ کپی (`Copy log`) و نوار وضعیت برای هر فایل بدون اسپم شدن خطوط لاگ (جایگزینی نرم در سطر فعال).
  - پشتیبانی کامل از نمایش پیشرفت هم در کپی مستقیم و هم در کپی محافظت‌شده با **Volume Shadow Copy (VSS)** و کپی پوشه‌های دستی.
  - نمایش وضعیت اعتبارسنجی هش SHA-256 در حین محاسبه برای دیتابیس‌های چند گیگابایتی.

## English

- **Live Percentage & Byte Progress for Large Database File Copies:**
  - Replaced opaque synchronous `File.Copy` with high-throughput streaming `CopyFileWithProgress` utilizing 1 MB sequential buffers.
  - Displays real-time copy percentage and transferred bytes in the copy log and status bar in-place, eliminating perceived UI freezes when copying multi-gigabyte files (e.g. 10+ GB MDFs).
  - Fully supports progress reporting for direct file copying, **Volume Shadow Copy (VSS)** snapshot copying, and manual folder traversal.
  - Informs user during post-copy SHA-256 integrity calculation so large file verification remains transparent.

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.
