# Database Finder v1.8.4

## فارسی

- **اسکن رنج شبکه:** در پنجره «اسکن شبکه» می‌توانید یک بازه از آدرس‌های IP، یک شبکهٔ محلی (با انتخاب خودکار رنج‌های کارت شبکه) یا یک آدرس CIDR را اسکن کنید. اسکن با هم‌زمانی محدود و مهلت هر میزبان اجرا می‌شود و روی هر یافت‌شده، نسخهٔ سرویس و نام نمونه (با پرس‌وجو از SQL Browser / SSRP) هم به‌دست می‌آید.
- **فیلتر «فقط پورت‌های باز»:** اسکن شبکه به‌صورت پیش‌فرض فقط پورت‌های باز را نشان می‌دهد؛ با یک تیک، همهٔ میزبان‌ها (از جمله Closed) هم دیده می‌شوند.
- **شناخت SQL Server بدون SSMS:** پرس‌وجوی SQL Browser (UDP 1434 / SSRP) اضافه شده تا نمونه‌های SQL Server همان‌طور که در «Browse → Network» اس‌اس‌ام‌اس پیدا می‌شوند، مستقیم در برنامه پیدا شوند.
- **احراز هویت ویندوز در اجرای کوئری:** گزینهٔ «احراز هویت ویندوز» درست مثل اس‌اس‌ام‌اس؛ اگر آدرس IP باشد، نام میزبان به‌صورت خودکار پیدا و برای NTLM امتحان می‌شود.
- **ستون «تعداد دیتابیس‌ها» در صفحهٔ اصلی:** برای هر سرویس آنلاین، تعداد واقعی دیتابیس‌های آن (با اتصال از طریق پروفایل ذخیره‌شده یا احراز هویت ویندوز) در یک ستون نمایش داده می‌شود.
- **دکمهٔ Close واقعاً می‌بندد:** کلیک روی X برنامه را می‌بندد (کوچک‌کردن همچنان به سینی می‌رود).
- دکمهٔ «اجرای کوئری» در نتایج اسکن شبکه برای هر ردیف (حتی در اسکن رنج) در دسترس است.

**فایل‌های اجرایی:** `DatabaseFinder-Light.exe` نسخه سبک و نیازمند .NET 8 Desktop Runtime برای Windows x64 است. `DatabaseFinder.exe` نسخه کامل و مستقل با .NET داخلی است. فایل `SHA256SUMS.txt` برای بررسی صحت هر دو دانلود ضمیمه شده است.

## English

- **Network range scanning:** the "Network Scan" window can scan a range of IP addresses, a local subnet (advertised interfaces are listed in a dropdown), or a CIDR block, with bounded parallelism and a per-host timeout. For every finding, the service version and instance name are resolved via a SQL Browser (SSRP, UDP 1434) probe.
- **"Open ports only" filter:** network scan results show only open ports by default; a check box brings back every host (including Closed).
- **SQL Server discovery without SSMS:** a SQL Browser (SSRP, UDP 1434) probe replaces the "Browse → Network" step of SSMS, so instance names and ports are found directly in the app.
- **Windows Authentication in Run Query:** Integrated Security like SSMS; for IP hosts the machine name is resolved and tried so NTLM/Kerberos works.
- **"# Databases" column on the main page:** for each online service the real database count (via a saved profile or Windows Authentication) is shown in a dedicated column.
- **Close button really closes:** pressing X exits the app (minimizing still goes to the tray).
- "Run Query" works on any selected row of network scan results, including range scans.

**Downloads:** `DatabaseFinder-Light.exe` requires .NET 8 Desktop Runtime for Windows x64. `DatabaseFinder.exe` is the standalone Windows x64 build with the runtime included. Verify either download using the attached `SHA256SUMS.txt`.
